Welcome to Zormid

Zormid is a web-based chat app designed for self-hosting with low-spec servers.

Why use Zormid?

  • Low server requirements
  • Self-hosted or use our server
  • No limits on message length

Limitations

  • Requires linux server
  • Only web clients
  • No message encryption

Note: Zormid is currently WIP and these will likely be addressed soon.
